# 🏭 What I Build at Work

### STITCH MES — Manufacturing Execution System
Multi-tenant platform helping apparel manufacturers optimize production, reduce waste and improve quality control.
- Owned backend architecture, multi-channel notification infrastructure and the Celery monitoring framework behind production observability.
- Cut report execution time **30–40%** and API response times **10–20%** via PostgreSQL query and index optimization.
- Built the in-product **AI assistant** end-to-end — document ingestion and embedding into Milvus, retrieval for RAG, and a LangGraph agent with tool calling for live report data.
- Built React.js screens and components against the DRF APIs.

### AurigaONE — Internal ERP
Foundational backend architecture and scalable REST APIs for employee reviews, leave management and operations workflows.
